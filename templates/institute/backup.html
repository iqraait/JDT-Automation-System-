Recovery & Restore Guide

If you need to restore your system using the backup ZIP file, follow these instructions carefully:

1

Extract the Codebase

Unzip the contents of the backup file into your application root folder (e.g. `/home/ubuntu/JDT-Automation-System-`). This will restore all features, HTML templates, CSS styles, and Python logic files.

2

Restore the Database

Copy the extracted `db.sqlite3` file into the root folder to overwrite the existing database file. All registered students, fee ledgers, payment details, and accounts will be recovered exactly.

3

Recover Student Document Uploads

Ensure the `media/` folder contents are extracted to the root path. This ensures student photos, signature files, and certificate uploads remain fully accessible.

4

Reboot Gunicorn Service

Restart the Django daemon service to apply changes. On your EC2 server, execute: sudo systemctl restart jdt.

Confidentiality & Data Protection Notice

Backup files contain highly sensitive personal databases and credentials. Store download files securely, restrict access to authorized staff, and avoid uploading backup files to public servers or code repositories.
